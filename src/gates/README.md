# Gates

Learned, content-based routing checkpoints between signals and parts. They inspect signal content, start from basic rules, and develop sophistication; they can broadcast to multiple parts at once.

**Governing ADRs:** ADR-0009

**Status:** Pending. DEPENDS ON NOVA enhancement #7 (learned routing tables atop core/channel.nova's filtered/weighted channels).
