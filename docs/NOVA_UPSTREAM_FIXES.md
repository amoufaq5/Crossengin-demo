# NOVA Upstream Fixes — Status

The eight NOVA runtime gaps CrossEngin's Phase 0-7 work surfaced landed
upstream in `amoufaq5/NOVA` (PRs #13-#20). PRs #21-#32 followed from the
2026-11-15 audit (secure_random, assert, CI, syscall tagging, time(), dead
code + licence, tagged runtime constants/maps, bounds checks, runtime/allocator fixes, LSP/versions, reseed). This doc is the pointer from
each NOVA fix to the CrossEngin workaround it retires. Remaining gaps are
listed under "Remaining NOVA gaps" below.

## When to retire the workarounds

Each dependent CrossEngin PR carries its own workaround commit. When
that PR is rebased against the current `claude/zealous-keller-NTz2n`
head, the rebaser can drop the workaround commit and revert the
callsite to the primitive — the upstream fix is in place.

PRs where the cleanup should happen on next rebase:
- [#21 — phase 2 Ollama](https://github.com/amoufaq5/Crossengin-demo/pull/21) — `src/nl/ollama_spawn.nova` + `/ingest_ollama`.
- [#25 — phase 5 agent Rx](https://github.com/amoufaq5/Crossengin-demo/pull/25) — `src/factory/agent_bundle.nova`.
- [#29 — phase 6 /mcp](https://github.com/amoufaq5/Crossengin-demo/pull/29) — re-import `src/io/effectors/effector_mcp.nova`.

The cleanup is intentionally not a single PR against the default
branch: the workaround code only exists on those feature branches,
so the cleanup commits belong there.

## Remaining NOVA gaps

The umbrella from `docs/NOVA_RUNTIME_GAPS.md §12` is fully closed for
the Phase 0-7 arc. Three gaps that pre-date this session remain open
upstream; none of them block a currently-shipped CrossEngin surface,
and Phase 3 pt2's search-engine effector is the only one that would
require an additional upstream fix before shipping:

- Missing `setenv()` — CrossEngin falls back to shell init + systemd
  `Environment=`.
- ~~`secure_random` seccomp-blocked in the dev sandbox~~ -- wrong diagnosis:
  it was a NOVA tagging bug (audit F-07), fixed in NOVA #21.
- ~~`sys_read` / `sys_write` return a raw byte count~~ -- fixed in NOVA #25
  (tag-correct syscall wrappers), adopted by CrossEngin #66.
- `envp=NULL` for a *strict* empty-env exec form — a new 3-arg
  `exec_program(path, argv, envp)` would replace the current
  inherit-by-default. Cosmetic; no caller needs it today.
- No in-process HTTPS — blocks Phase 3 pt2's `src/io/effectors/search_engine.nova`.

All exec, fork, pipe, read/write, and module-dedup gaps that surfaced
during Phases 0-7 are closed.
