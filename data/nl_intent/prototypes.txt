# CrossEngin NL intent-classifier training corpus (R98, Phase C part 3).
#
# Line-oriented format:
#   # ...        -- comment (ignored)
#   KIND <name>  -- start of a block for one SQ kind
#   <utterance>  -- one training utterance (indent optional; leading/trailing
#                   whitespace is trimmed)
#
# The kind name is a case-sensitive lowercase token matching one of the
# SQ kind constants in src/nl/query_shape.nova, minus the `NLK_` prefix:
#   research, relate, contradict_scan, is_a, retract,
#   capsule_install, skill_install, capsule_list, skill_list, skill_run.
# NONE and UNPARSED are deliberately absent -- the classifier only runs
# AFTER the grammar returned NLK_UNPARSED, so classifying "into" UNPARSED
# would be a no-op, and NONE (filler) is caught upstream by the grammar.
#
# For R98 the classifier ALSO carries a hard-coded embed of this same
# corpus inside src/nl/nl_intent_classifier.nova so no runtime file I/O
# is required at daemon boot (sys_open under the container sandbox
# aborts on /tmp, and reading a data file at start pulls in the same
# hazard). This .txt is shipped for operator inspection; keep the code
# and the file in sync when adding new utterances (a future round can
# unify them).
#
# Domain diversity is deliberate: prototypes must generalize across
# biology / physics / history / ops / meta vocab, so no single-topic
# corpus can lock the prototype vector to one lexicon.
