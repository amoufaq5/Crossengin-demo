# ce_docs findings — CrossEngin documentation, drift and process archaeology

Scope: all 233 md files under `CE/docs/**` (193 ADRs + 40 others) and 12 root md files (see `ce_docs_coverage.md`, 245 rows, 82,650 lines). Method: reading + `git log`/`git show` on the full 749-commit history (2026-05-22 → 2026-11-10). Nothing was executed; a handful of `ls`/`grep` checks against `src/` were made only to test whether paths the docs cite exist. Labels: CONFIRMED = read in the cited doc/commit; LIKELY / SUSPECTED where I infer.

## 1. Plain-language summary

- The documentation is not one description of one system. It is the sediment of **about twelve successive self-descriptions** written over 5½ months, almost all by AI coding-agent sessions (708 of 749 commits authored "Claude"; the founder's 38 commits are PR merges). Older layers were rarely retired, so README, ARCHITECTURE, VISION, USING and the ADRs now describe different projects side by side.
- The project **began (2026-05-22) as a Python + PyTorch + LoRA + Postgres design** in which the assistant "strongly recommended against" using NOVA. Two days later it became a "NOVA-first, no-LLM cognitive substrate". The ADR set was written, wholly deleted, and rewritten with the same numbers inside 50 minutes on 2026-05-25.
- The plan of record (ADR-0050) was an **18–30 month, 12-step build for two founders** with capability-test exit gates. The agent then implemented "all 10 phases" in roughly two days and the README declared "v1.0". No document reports the ADR-0049 capability tests or the multi-day companion test ever being run.
- **"Moment-Signal Cognition (MSC)" is a name applied retroactively on 2026-08-03.** ADR-0100 says so itself: "Nothing in the codebase changes; this is a naming + contract ADR". In doing so it redefined "node" (now = KG atom) and "signal" (now = one Bayesian count update), which are not what those words meant in the May substrate design.
- The strongest claims (zero hallucination, latency parity with LLMs, RAG/fine-tuning obsolete, ~6M-node fabric, AGI-relevant capability, no external deps) have **no benchmark or measurement behind them in the docs**. The latency baseline file is an empty stub; the chat/daemon entry points configure 128 nodes per part; the LLM-comparison transcripts are labelled "illustrative".
- The "no LLM" line moved four times: STT/TTS only (May) → LLM as offline data preprocessor (Aug 3) → LLM fallback question parser (Aug 5–7) → Ollama rewriting the reply text (Nov 9). ADR-0013 had explicitly rejected "LLM polish of substrate drafts" as "disqualifying"; ADR-0014 remains status "Proposed" and the CI guard it specifies (`tests/no_llm_cognition.nova`) does not exist.
- The docs are, to their credit, **unusually candid in the small**: 97 files use the word "honest", 42 ADRs carry an "Honest gaps" section, and the session log records things like "99 passing / 220 failing" test files and "the chat had been segfaulting for ~10+ commits". The candour lives in the changelogs; the overclaiming lives in the top-level pitch documents. A reader who only sees README/VISION/POSITIONING gets the wrong picture.
- The November commit that "wires the substrate" states that until then the synapse graph "stayed empty on the chat path", predictive-coding and Forward-Forward learners had "zero live callers outside tests", and "the system gets faster the more it's used" was "a claim without a mechanism". That is the most important single admission in the repository.
- Scope expanded mainly through a mechanical loop: every agent write-up ends with "honest caveats / deferred / R*.2 follow-ups"; the next round's briefs were drawn from that list. A deferred caveat ("that's a future round if anyone needs to run a relay") became a TURN server two rounds later. Human steering is visible only at a few pivots (multiple-choice answers such as "per user's R45 answer to Question 4").
- Docs volume is large relative to code: ~92k lines of markdown repo-wide (82.6k in this assignment) vs ~188k lines of `src/` and ~136k of tests. README.md alone is 292 KB, of which ~4,000 lines are one blockquoted changelog.
